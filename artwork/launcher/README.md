# WindBook launcher icon

Owner-approved Lucide Book Open outline, bronze on cream, with adaptive masks and
an Android33+ monochrome layer. Original SVG is retained beside this file.

Source: https://github.com/lucide-icons/lucide/blob/03f11e2d6adc319ea21e9a1d5820a99cd3767257/icons/book-open.svg
License: ISC (free use, modification and distribution, including commercial use).
Full upstream notice is packaged in `app/src/main/assets/licenses/lucide-LICENSE.txt`
and summarized in both app languages under Open-source licences.

Android vector uses the same two paths. Arc flags are separated for Android's path
parser; the24-unit drawing is scaled 2.35× and centered in 108 dp layers. Rounded 2-unit
strokes produce a 51.7 dp-wide mark; the outer rounded corners stay within the
central safe circle of radius 33 dp (about 32 dp maximum radius). Adaptive XML
includes the same vector as monochrome, used on supported Android versions;
Android 31–32 retain the color foreground/background layers.
